# rules.md — hard constraints for every post (T2 turns these into `lint_post`)
- 280 characters max, or a thread where every tweet stands alone.
- No links in the post body (links cost ~13x more via API and hurt reach; put them in a reply or bio).
- Max 2 hashtags. No banned phrases: game-changer, unlock, delve, 🚀, "thread 🧵".
- Never claim something you have not verified. If unsure, say "I think" or leave it out.
- Never post, like, follow or reply automatically. The agent drafts; the human taps Post.
- Do not draft anything for posting between 00:00 and 07:00 IST.
- Replies to other people are drafted into a queue for the human to send manually (X restricts automated replies).
