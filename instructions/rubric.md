# rubric.md — used by the critic to score a draft post (1-5 each; ship at >= 4 average, no score below 3)
- **Specific**: contains one concrete fact, number, example or code idea. (no vague hype)
- **Correct**: nothing stated that the learning log does not support.
- **Clear**: a smart beginner understands it in one read.
- **Hook**: first line gives a reason to keep reading, without clickbait.
- **Voice**: sounds like voice.md, not like a generic AI.
