Module `xbot/lint.py` — turns `instructions/rules.md` into code.

`lint_post(text: str) -> list[str]` returns a list of violation codes (empty list = clean). Codes, in this order of checking:
- `empty` — text is empty or only whitespace (return just `["empty"]`).
- `too_long` — more than 280 characters.
- `has_link` — contains `http://`, `https://` or `www.`.
- `banned_phrase` — contains (case-insensitive) any of: `game-changer`, `game changer`, `unlock`, `delve`, `🚀`, `thread 🧵`.
- `too_many_hashtags` — more than 2 words starting with `#`.
Each code appears at most once.
