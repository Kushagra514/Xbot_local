Module `bot/knowledge_reader.py` — read-only access to the `knowledge/` folder (the bot's content source).

- `read_knowledge(knowledge_dir="knowledge") -> list[Learning]`
- `Learning(path, title, body, pillar)` dataclass.
- Skips `README.md`. Title = first H1 heading, else filename stem.
- Pillar = `Pillar: <name>` first line if present, else `"general"`.
- Returns list sorted by filename. No network, stdlib only.
