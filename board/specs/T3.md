Module `xbot/dedupe.py` — stop the bot repeating itself (no embeddings yet; plain word overlap).

- `similarity(a: str, b: str) -> float` — Jaccard similarity of the sets of lowercase words (split on non-alphanumeric
  characters, ignore empty tokens). Two empty texts -> `0.0`.
- `is_duplicate(text: str, past: list[str], threshold: float = 0.6) -> bool` — True if any past text has
  `similarity >= threshold` with `text`.
