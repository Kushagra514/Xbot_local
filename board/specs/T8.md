Module `bot/pipeline.py` — closed-loop draft pipeline (Mode A).

Flow per learning: knowledge -> draft (local Qwen) -> lint (rules) -> dedupe (past posts) -> critic (rubric)
-> [one bounded revision if needed] -> queue in SQLite (status=drafted) -> compose link (human taps Post).

- `run_pipeline(...)` drafts from knowledge/ and prints each post's `x.com/intent/post?text=...` link.
- `rate_post(post_id, rating, notes)` logs free human feedback to the `feedback` table for "best performing" review.
- No network to X; stdlib + local Ollama only.
