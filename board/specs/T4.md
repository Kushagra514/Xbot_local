Module `xbot/compose.py` — Mode A publisher: builds a pre-filled X compose link the human opens and taps Post on.

- `compose_url(text: str) -> str` — returns `https://x.com/intent/post?text=` followed by the text percent-encoded
  with `urllib.parse.quote(text, safe="")`.
- Empty/whitespace-only text -> `ValueError`. More than 280 characters -> `ValueError`.
- This module must not open a browser or touch the network; it only builds a string.
