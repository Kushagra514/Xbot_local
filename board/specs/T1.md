Module `xbot/db.py` — SQLite state for the post queue (stdlib `sqlite3`).

- `init_db(path: str) -> sqlite3.Connection` — creates table `posts(id INTEGER PRIMARY KEY, text TEXT NOT NULL,
  pillar TEXT NOT NULL, status TEXT NOT NULL, created_at TEXT NOT NULL)` if missing; rows returned as dict-like (`sqlite3.Row`).
- Valid statuses: `drafted`, `approved`, `posted`, `skipped`.
- `add_post(conn, text: str, pillar: str, status: str = "drafted") -> int` — returns the new id; invalid status -> `ValueError`.
- `set_status(conn, post_id: int, status: str) -> None` — invalid status -> `ValueError`; unknown id -> `KeyError`.
- `get_post(conn, post_id: int) -> dict` — plain dict with keys id, text, pillar, status, created_at; unknown id -> `KeyError`.
- `next_day_number(conn) -> int` — number of posts with status `posted`, plus 1 (for the "Day N/100" series).
- `past_texts(conn) -> list[str]` — texts of posts with status `posted`, oldest first.
