Module `bot/draft_post.py` — draft one X post from a Learning using the local Qwen model via Ollama.

- `draft_post(learning, voice, rules, pillars) -> str`
- Returns draft text (<=280 chars expected, no links). Mode A: draft only, never calls the X API.
- Calls `OLLAMA_HOST/api/chat` with `OLLAMA_MODEL` (default qwen3.5:4b-q4_K_M), `NUM_CTX` default 8192.
