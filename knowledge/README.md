# knowledge /

Drop your AI/ML learnings here as markdown files. Each file = one learning that the bot can turn into a draft post.

Convention: `YYYY-MM-DD-<slug>.md`. Front-matter is optional; the reader takes the first H1 as the title and the rest as the body. Pillar is inferred from the folder/file or set via `Pillar: <name>` on the first line.

These files are YOUR knowledge base — the agent only reads them, never writes to X directly (Mode A).
